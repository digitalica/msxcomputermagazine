Screen5-12 converter (2)
Genic Clubguide, 00-00-00

    
VERVOLG:

       S C R E E N   5 / 1 2   S U P E R I M P O S E
      ===============================================

(Nvdr. Deze  tekst was  te lang voor de layout van ClubGuide 
Special.  Daarom hebben  we de tekst in twee stukken gehakt. 
Dit is  het tweede  deel, het eerste deel kunt u in het menu 
vinden.  We  pakken  de  draad  weer  op  bij het  punt waar 
het andere deel stopte.)

; Maak de regel af

        INC   HL              ; volgende sc5 pixels
        INC   DE              ; volgende sc12 pixel
        DJNZ  CNV_1           ; maak de regel af

Hier  worden  de  IX  en  IY  registers op  de juiste  wijze 
verhoogd, zodat  ze nu  naar het begin van de volgende regel 
wijzen.

; Volgende regel

        LD    DE,256          ; een sc12 regel telt
                              ; 256 bytes
        ADD   IY,DE           ; adres sc12 een regel verder
        LD    DE,128          ; een sc5 regel telt 128 bytes
        ADD   IX,DE           ; adres sc5 een regel verder
