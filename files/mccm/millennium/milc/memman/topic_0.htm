How to obtain (undocumented) MemMan info ?
==========================================

1st - find out where MemMan is (which DOS-segment)
2nd - search for the string #FE #FD
3rd - position of byte containing #FE is presented by 'x'
	x+.. \ default command string
	x+ 2 / when MemMan is installed
	x+ 1 = #FD
	x+ 0 = #FE
	x- 1 \ Maximum heap
	x- 2 / length
	x- 3 Maximum hook entries
	x- 4 Maximum TSR entries
	x- 5 Recursion depth

Note: This information is at least legal with v2.4 and since MST is never to
      be seen again (I think - seen some latest software ?? no ? neither
      have I) , you can use this information if you think you need them.
      Changing the settings is not a smart thing to do , because MemMan
      may crash.
